# Курсовой проект «Реализация программы контроля облачной инфраструктуры»

## Контрольная точка 1 (КТ1): Пять тестовых значений — формулы и базовый контроль

Программа предназначена для анализа телеметрии и автоматизированного контроля состояния компонентов облачной инфраструктуры по временным рядам измерений.

### Вариант 14

* **Компоненты:** `HDD`, `SSD`, `APP`
* **Порядок записи во входных данных:** формат `Б` (`значение;время;компонент`, разделитель — точка с запятой `;`).
* **Тип последовательности (2):** порядок компонентов произвольный; на каждом отсчёте присутствуют все три компонента.
* **Телеметрия за пять отсчётов (одна строка):**
  ```text
  43.7;1;HDD;53.2;4;SSD;44.7;3;HDD;53.8;1;SSD;51.1;5;HDD;34.5;5;APP;55.2;3;SSD;50.6;4;HDD;35.2;4;APP;57.2;2;SSD;30.6;3;APP;32.0;1;APP;44.2;2;HDD;31.3;2;APP;51.2;5;SSD
  ```
* **Производный показатель $Q$:** Относительное изменение $Q[i] = \frac{X[i] - X[i-k]}{X[i-k]}$
  Параметры: $k = 2$, $L = 1.5$, $D = 20$.
* **Правило состояния компонента (Сравнение с критерием $L$):**
  Если $Q < -L$ (где $-L = -1.5$), фиксируется состояние **«СНИЖЕНИЕ»**; если $-L \le Q \le L$ ($-1.5 \le Q \le 1.5$) — **«НОРМА»**; если $Q > L$ ($Q > 1.5$) — **«РОСТ»**.
* **Правило инцидента (Два из трёх):**
  Инцидент возникает, если не менее двух компонентов одновременно находятся в состоянии, отличном от «НОРМА»:
  Incident(t) = ((S<sub>HDD</sub>[t] ≠ НОРМА) ∧ (S<sub>SSD</sub>[t] ≠ НОРМА)) ∨ ((S<sub>HDD</sub>[t] ≠ НОРМА) ∧ (S<sub>APP</sub>[t] ≠ НОРМА)) ∨ ((S<sub>SSD</sub>[t] ≠ НОРМА) ∧ (S<sub>APP</sub>[t] ≠ НОРМА))
* **Структура Incident:**
  ```c
  typedef struct {
      int time;
      int type;
  } Incident;
  ```
  Поля: номер отсчёта (`time`), тип инцидента (`type`).

## 1. Алгоритм работы программы

### Описание алгоритма

1. Задать массивы телеметрии из карточки варианта для трёх компонентов (`HDD`, `SSD`, `APP`) на 5 отсчётов времени ($t = 1 \dots 5$).
2. Задать параметры: шаг сравнения $k = 2$, порог критерия $L = 1.5$.
3. Для каждого компонента вычислить относительное изменение $Q[i]$ для отсчётов $t = 3, 4, 5$ (для $t = 1, 2$ пары со сдвигом $k = 2$ отсутствуют).
4. Определить состояние компонентов:
   * для отсчётов $t = 1, 2$ данных недостаточно $\rightarrow$ статус «НОРМА»;
   * для отсчётов $t = 3, 4, 5$ сравнить $Q[i]$ с критерием $L$: если $Q[i] < -L$, статус «СНИЖЕНИЕ»; если $-L \le Q[i] \le L$, статус «НОРМА»; если $Q[i] > L$, статус «РОСТ».
5. Проверить возникновение инцидента по правилу «Два из трёх»: если не менее двух компонентов из списка (`HDD`, `SSD`, `APP`) не в состоянии «НОРМА», зафиксировать инцидент в структуре `Incident`, сохранив номер отсчёта и тип инцидента.
6. Вывести исходные данные, показатели $Q$, состояния компонентов и журнал инцидентов.

### Исходные данные телеметрии (упорядочены по отсчётам)

### Ручной расчёт производного показателя $Q$ ($k = 2$)

* **Отсчёт $t = 3$ (пара с $t = 1$):**
  * $\text{HDD}: Q[3] = \frac{44.7 - 43.7}{43.7} = \frac{1.0}{43.7} \approx +0.023$
  * $\text{SSD}: Q[3] = \frac{55.2 - 53.8}{53.8} = \frac{1.4}{53.8} \approx +0.026$
  * $\text{APP}: Q[3] = \frac{30.6 - 32.0}{32.0} = \frac{-1.4}{32.0} \approx -0.044$

* **Отсчёт $t = 4$ (пара с $t = 2$):**
  * $\text{HDD}: Q[4] = \frac{50.6 - 44.2}{44.2} = \frac{6.4}{44.2} \approx +0.145$
  * $\text{SSD}: Q[4] = \frac{53.2 - 57.2}{57.2} = \frac{-4.0}{57.2} \approx -0.070$
  * $\text{APP}: Q[4] = \frac{35.2 - 31.3}{31.3} = \frac{3.9}{31.3} \approx +0.125$

* **Отсчёт $t = 5$ (пара с $t = 3$):**
  * $\text{HDD}: Q[5] = \frac{51.1 - 44.7}{44.7} = \frac{6.4}{44.7} \approx +0.143$
  * $\text{SSD}: Q[5] = \frac{51.2 - 55.2}{55.2} = \frac{-4.0}{55.2} \approx -0.072$
  * $\text{APP}: Q[5] = \frac{34.5 - 30.6}{30.6} = \frac{3.9}{30.6} \approx +0.127$

| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |

Ожидаемый результат: на всех доступных отсчётах **3**, **4** и **5** значения показателя $Q$ лежат в пределах диапазона $[-1.5; 1.5]$, поэтому все компоненты (`HDD`, `SSD`, `APP`) находятся в состоянии «НОРМА», и инциденты не возникают.

## 3. Реализация программы

```c
#include <stdio.h>
#include <locale.h>
#define N 5

typedef struct {
    int time;
    int type;
} Incident;

int evaluate_state(float q, float l_crit) {
    if (q < -l_crit) {
        return -1;
    }
    else if (q > l_crit) {
        return 1;
    }
    return 0;
}

const char* state_to_str(int state) {
    if (state == -1) return "СНИЖЕНИЕ";
    if (state == 1)  return "РОСТ";
    return "НОРМА";
}

int main(void) {
    setlocale(LC_ALL, "");

    float hdd[N] = { 43.7f, 44.2f, 44.7f, 50.6f, 51.1f };
    float ssd[N] = { 53.8f, 57.2f, 55.2f, 53.2f, 51.2f };
    float app[N] = { 32.0f, 31.3f, 30.6f, 35.2f, 34.5f };

    const int k = 2;
    const float L = 1.5f;

    float q_hdd[N] = { 0.0f };
    float q_ssd[N] = { 0.0f };
    float q_app[N] = { 0.0f };

    int st_hdd[N] = { 0 };
    int st_ssd[N] = { 0 };
    int st_app[N] = { 0 };

    Incident incidents[N];
    int incident_count = 0;

    for (int i = k; i < N; i++) {
        q_hdd[i] = (hdd[i] - hdd[i - k]) / hdd[i - k];
        q_ssd[i] = (ssd[i] - ssd[i - k]) / ssd[i - k];
        q_app[i] = (app[i] - app[i - k]) / app[i - k];
        st_hdd[i] = evaluate_state(q_hdd[i], L);
        st_ssd[i] = evaluate_state(q_ssd[i], L);
        st_app[i] = evaluate_state(q_app[i], L);

        int is_incident = ((st_hdd[i] != 0) && (st_ssd[i] != 0)) ||
            ((st_hdd[i] != 0) && (st_app[i] != 0)) ||
            ((st_ssd[i] != 0) && (st_app[i] != 0));

        if (is_incident) {
            incidents[incident_count].time = i + 1;
            incidents[incident_count].type = 1;
            incident_count++;
        }
    }
    printf("Контроль облачной инфраструктуры\n\n");
    printf("Исходные данные телеметрии:\n");
    printf("Отсчет\tHDD\tSSD\tAPP\n");
    for (int i = 0; i < N; i++) {
        printf("%d\t%.1f\t%.1f\t%.1f\n", i + 1, hdd[i], ssd[i], app[i]);
    }
    printf("\nОтносительное изменение Q при k = %d:\n", k);
    printf("Отсчет\tQ(HDD)\tQ(SSD)\tQ(APP)\n");
    for (int i = k; i < N; i++) {
        printf("%d\t%+.3f\t%+.3f\t%+.3f\n", i + 1, q_hdd[i], q_ssd[i], q_app[i]);
    }
    printf("\nСостояние компонентов (порог L = %.1f):\n", L);
    printf("Отсчет\tHDD\tSSD\tAPP\n");
    for (int i = 0; i < N; i++) {
        printf("%d\t%s\t%s\t%s\n",
            i + 1,
            state_to_str(st_hdd[i]),
            state_to_str(st_ssd[i]),
            state_to_str(st_app[i]));
    }
    printf("\nЖурнал инцидентов (правило \"Два из трёх\"):\n");
    if (incident_count == 0) {
        printf("Инцидентов не зафиксировано.\n");
    }
    else {
        for (int i = 0; i < incident_count; i++) {
            printf("Отсчет %d: зафиксирован инцидент (тип %d)\n",
                incidents[i].time, incidents[i].type);
        }
    }
    return 0;
}
```
